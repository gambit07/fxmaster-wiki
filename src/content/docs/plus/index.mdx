## Additional features

| Feature | What it adds |
|---|---|
| Custom Particle Effects | Creates user-defined effects from [Directional Drift](../reference/effects/details/custom-directional-drift/), [Ambient Float](../reference/effects/details/custom-ambient-float/), [Manual Placement](../reference/effects/details/custom-manual-placement/), or [Sound Only](../reference/effects/details/custom-sound-only/) bases. |
| Sound Effects Manager | Connects effects to environmental or token-movement sounds. |
| Water Module Settings | Removes unused [Water](../reference/effects/details/water/) feature groups from the Water shader. |
| Wind Painting | Paints the areas where the [Wind](../reference/effects/details/wind/) filter should affect the Scene or Region. |
| Suppress Scene Sounds | Adds a Region behavior with independent controls for suppressing Scene-level Environmental and Token Movement SoundFX rules. |

## How FXMaster+ fits in

FXMaster+ effects appear in the same particle, filter, Region, layer, preset, macro, and API tools used by FXMaster. It does not replace the core module or create a separate effect stack; it adds more options to the existing FXMaster setup.
