---
title: Accessing FXMaster+
description: Subscribe through Gambit’s Lounge, link Patreon to Foundry VTT, restart the server, and install FXMaster+.
---

FXMaster+ is available through [Gambit’s Lounge on Patreon](https://www.patreon.com/cw/GambitsLounge). Patreon must be linked directly to the Foundry VTT account used by the server before Foundry can make the module available for installation.

<div class="fxm-flow">
  <div>
    <h3><a class="fxm-lounge-link" href="https://www.patreon.com/cw/GambitsLounge">Subscribe through Gambit’s Lounge</a></h3>
    <p>Subscribe to one of the following tiers to access the modules:</p>
    <ul>
      <li>Queen of Hearts</li>
      <li>King of Diamonds</li>
      <li>Ace of Spades</li>
      <li>OMEGA LEVEL</li>
    </ul>
    <p><strong>Early access modules:</strong> Subscribe to the Ace of Spades or OMEGA LEVEL tier.</p>
    <p><a class="fxm-lounge-link" href="https://www.patreon.com/cw/GambitsLounge">Open Gambit’s Lounge on Patreon →</a></p>
  </div>
  <div>
    <h3>Link Patreon to Foundry VTT</h3>
    <p>Sign in at foundryvtt.com, open <a href="https://foundryvtt.com/me/edit">Edit Profile</a>, and link the Patreon account used for the subscription. Confirm that <a class="fxm-lounge-link" href="https://www.patreon.com/cw/GambitsLounge">Gambit’s Lounge</a> appears under <a href="https://foundryvtt.com/me/subscriptions">Subscribed Content</a>.</p>
    <ul>
      <li><strong>Hosted servers:</strong> When using The Forge or another hosted service, Patreon still needs to be linked directly to the Foundry VTT account. Patreon linking offered by the hosting provider for its own services is separate and is not used for this integration.</li>
    </ul>
  </div>
  <div>
    <h3>Restart the Foundry server</h3>
    <p>Restart the full Foundry server after subscribing or linking Patreon. Foundry often will not recognize a newly linked Patreon account until the server has restarted. Reloading only the world may not be enough.</p>
  </div>
  <div>
    <h3>Install the module</h3>
    <p>From the Foundry Setup screen, open <strong>Add-on Modules</strong>, select <strong>Install Module</strong>, and search for any modules included with the subscription:</p>
    <ul>
      <li><a href="https://foundryvtt.com/packages/fxmaster-plus"><strong>Gambit’s FXMaster+</strong></a></li>
      <li><a href="https://foundryvtt.com/packages/gambitsGames"><strong>Gambit’s Games</strong></a></li>
      <li><a href="https://foundryvtt.com/packages/gambitsAssetPreviewer"><strong>Gambit’s Asset Previewer</strong></a></li>
      <li><a href="https://foundryvtt.com/packages/gambitsImageViewer"><strong>Gambit’s Image Viewer</strong></a></li>
    </ul>
    <p>Install the intended module, then enable it in the world. <strong>Gambit’s FXMaster</strong> must also be installed and active before enabling <strong>Gambit’s FXMaster+</strong>.</p>
  </div>
</div>

## Hosted service installation problems

- If The Forge or another hosted provider cannot add the module, open a troubleshooting case with that provider. Hosted installation issues are generally on the provider’s side, and I will likely be unable to resolve them from my side.
- Confirm that the correct Patreon account is linked at foundryvtt.com before contacting the provider.
- Restart the hosted Foundry server after changing the Patreon connection or subscription tier.
