Filter effects change the rendered Scene image instead of adding individual particle sprites. They can cover the full Scene, stay inside a Region, display at different points in the layer stack, use Scene Levels and darkness controls, and support painted areas where available.

Select <span class="fxm-control-label" data-control="filters">Filter Effects</span> from <span class="fxm-control-label" data-control="effects">FXMaster Controls</span> to open **Filter Effects Management**. This is the recommended way to add filter effects because it provides the complete FXMaster parameter set, layer placement, multiple effect rows, darkness controls, Sound FX controls when available, and other effect-specific options.

Open the overflow menu in **Filter Effects Management** and select **Hide Filter Effects** to declutter the management list. This window is per-user and only changes whether an effect is shown in the Filter Effects manager. It does not delete the effect, and it does not prevent macros, presets, or the API from enabling that effect.

Use the row toggle to hide or show each effect in the management list. Hidden effects can be re-enabled from the same window later.
