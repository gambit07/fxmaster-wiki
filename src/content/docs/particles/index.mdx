Particle effects add moving sprites or procedural particles over the Scene. They can cover the full Scene, stay inside a Region, display below tokens or tiles, activate only at selected darkness levels, and use supported background or token-interaction options.

Select <span class="fxm-control-label" data-control="particle-effects">Particle Effects</span> from <span class="fxm-control-label" data-control="effects">FXMaster Controls</span> to open **Particle Effects Management**. This is the recommended way to add particle effects because it provides the complete FXMaster parameter set, layer placement, multiple effect rows, backgrounds, token interactions, Sound FX controls when available, and other effect-specific options.

FXMaster also registers its particle effects in Foundry's standard **Weather Effects** field. In the Scenes directory, right-click a Scene, select **Edit**, and choose an FXMaster particle effect through **Weather Effect**. FXMaster entries are labeled with the effect name followed by **(FXMaster)**.

:::caution[Usually not the recommended workflow]
Foundry's **Weather Effect** field is available if needed, but most users should avoid it for normal FXMaster setup. It uses Foundry's basic weather-effect implementation and applies the selected effect without FXMaster customization and does not expose the full FXMaster control set. In most scenarios, use <span class="fxm-control-label" data-control="particle-effects">Particle Effects</span> instead so the effect can be configured properly.
:::

Use the Foundry Scene field only when a quick default effect is sufficient and no FXMaster-specific customization is needed.

Open the overflow menu in **Particle Effects Management** and select **Hide Particle Effects** to declutter the management list. This window is per-user and only changes whether an effect is shown in the Particle Effects manager. It does not delete the effect, and it does not prevent macros, presets, or the API from enabling that effect.

Use the row toggle to hide or show each effect in the management list. Hidden effects can be re-enabled from the same window later.
