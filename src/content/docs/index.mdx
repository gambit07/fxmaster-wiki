FXMaster is a real-time visual effects module within Foundry that includes Scene or Region based particle and filter effects. FXMaster+ is an expansion module that is installed in addition to FXMaster with additional effects and features. Use these guides to set up effects, understand how they behave, see what each parameter changes on the canvas, and more!
