Rising or top-down bubbles with orbiting, synchronized direction, and token trail interactions.

Ambient effects add visible movement without replacing the full weather setup. Use them on their own or layer them with another particle or filter.

## Important controls

- **Top Down:** Switches Bubbles to the overhead presentation intended for top-down maps. This changes particle projection and movement, so set it before finalizing scale and direction.
- **Directional Movement:** Makes bubbles travel in the configured Direction instead of relying only on the effect's default random movement.
- **Synchronized Direction:** Uses the active Wind or Duststorm direction for Bubbles. When the source direction changes, this effect follows it.
- **Token Trails:** Pop bubbles that moving tokens pass through.
- **Trail Width:** Sets the bubble pop path width as a multiplier of the moving token's footprint.

## Setup notes

- Top Down is intended for overhead maps and can pair well with [Underwater](../underwater/) or [Water](../water/).
- Token Trails create temporary openings through the bubbles. Tune Trail Width before increasing Trail Strength.

## Direct-effect API example

The Direct Effect API creates a separate row shown through <span class="fxm-control-label" data-control="api-effects">Manage API Effects</span>. Add a stable `apiMacro_…_p` or `apiMacro_…_f` ID when later macro calls need to update or stop the same row.

```js
const created = await FXMASTER.api.effects.play({
  particles: [{
    "id": "apiMacro_wikibubbles_p",
    "type": "bubbles",
    "options": {
      "belowTokens": false,
      "tint": {
        "value": "#FFFFFF",
        "apply": false
      },
      "topDown": false,
      "orbit": false,
      "directionalMovement": false
    }
  }],
});

await FXMASTER.api.effects.particles.stop(created.particles);
```

For complete API behavior, scene targeting, stack ordering, and toggle groups, see the [Direct Effect API](../../../../automation/effect-api/) guide.
