Animated bat swarms with orbit, directional movement, lateral drift, and optional shadows.

Animal effects add moving subjects to a Scene without creating tokens. Scale and Density control the population, while the available movement controls determine how they travel around the map.

## Important controls

- **Orbit:** Makes bats circulate around the effect area instead of only crossing the canvas in a straight or drifting path.
- **Directional Movement:** Makes bats travel in the configured Direction instead of relying only on the effect's default random movement.
- **Shadow:** Adds a separate projected shadow beneath bats to give the effect more depth against the map.
- **Shadow Only:** Hides bats and renders only their projected shadows.
- **Density:** Changes how many bats are visible or spawned at once. It does not change their size.

## Setup notes

- Orbit works well when bats should circle a cave chamber, tower, or other focal point. Directional Movement is better when they should cross a wider map.
- Shadow Only can suggest bats passing above the ground without showing the bat sprites themselves.

## Direct-effect API example

The Direct Effect API creates a separate row shown through <span class="fxm-control-label" data-control="api-effects">Manage API Effects</span>. Add a stable `apiMacro_…_p` or `apiMacro_…_f` ID when later macro calls need to update or stop the same row.

```js
const created = await FXMASTER.api.effects.play({
  particles: [{
    "id": "apiMacro_wikibats_p",
    "type": "bats",
    "options": {
      "belowTokens": false,
      "tint": {
        "value": "#FFFFFF",
        "apply": false
      },
      "orbit": false,
      "directionalMovement": false,
      "scale": 0.27
    }
  }],
});

await FXMASTER.api.effects.particles.stop(created.particles);
```

For complete API behavior, scene targeting, stack ordering, and toggle groups, see the [Direct Effect API](../../../../automation/effect-api/) guide.
