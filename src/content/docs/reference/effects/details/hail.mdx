## Important controls

- **Top Down:** Switches Hail to the overhead presentation intended for top-down maps. This changes particle projection and movement, so set it before finalizing scale and direction.
- **Direction:** Sets the primary travel direction for hail particles. Directional Spread can add variation around this angle.
- **Synchronized Direction:** Uses the active Wind or Duststorm direction for Hail. When the source direction changes, this effect follows it.
- **Scale:** Changes the rendered size of hail particles. It does not change how many particles are present.
- **Density:** Changes how many hail particles are visible or spawned at once. It does not change their size.

## Setup notes

- Top Down changes the hail projection and should be selected before tuning Scale and Direction.
- Hail is visually strong, so moderate Opacity and Density values usually preserve token readability better.

## Direct-effect API example

The Direct Effect API creates a separate row shown through <span class="fxm-control-label" data-control="api-effects">Manage API Effects</span>. Add a stable `apiMacro_…_p` or `apiMacro_…_f` ID when later macro calls need to update or stop the same row.

```js
const created = await FXMASTER.api.effects.play({
  particles: [{
    "id": "apiMacro_wikihail_p",
    "type": "hail",
    "options": {
      "belowTokens": false,
      "tint": {
        "value": "#FFFFFF",
        "apply": false
      },
      "topDown": false,
      "scale": 0.27,
      "speed": 0.18
    }
  }],
});

await FXMASTER.api.effects.particles.stop(created.particles);
```

For complete API behavior, scene targeting, stack ordering, and toggle groups, see the [Direct Effect API](../../../../automation/effect-api/) guide.
